# AppView indexing

The repository does not provide a maintained standalone AppView indexer. The [feed generator](/architecture/feed-generator) maintains its own boundary-scoped projection. For a custom consumer, see [AppView integration](/operator/appview-integration). The former indexer design remains in [repository history](https://github.com/NorthskySocial/stratos/blob/6ec7750d/docs/architecture/appview-indexer.md).
